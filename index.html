Sección I

Fundamento Matemático de los Sistemas Posicionales

Un sistema de numeración posicional de base (o raíz) b, donde b ∈ ℕ y b ≥ 2, es una representación simbólica en la cual el valor cuantitativo de cada dígito depende tanto de su símbolo intrínseco como de la posición relativa que ocupa dentro de la cadena numérica respecto al punto radical.

Teorema Fundamental de la Numeración Posicional

Sea b ∈ ℕ con b ≥ 2. Todo número real positivo N puede expresarse de forma única en base b mediante una secuencia finita de dígitos enteros para su parte entera y una secuencia finita o infinita para su parte fraccionaria:

N(b) = (dn dn-1 … d1 d0 . d-1 d-2 … d-m)(b) = ∑i = -mn di · bi

Donde cada coeficiente di ∈ ℤ satisface la condición estricta de acotación 0 ≤ di < b. Para bases superiores a 10 (b > 10), se emplean las letras mayúsculas del alfabeto latino (A = 10, B = 11, C = 12, …, Z = 35) para representar dígitos individuales.

Algoritmo A: De Base b a Base 10 (Expansión Polinómica)

Para convertir una representación N(b) al sistema decimal (base 10), se evalúa directamente el polinomio posicional en potencias de b usando aritmética en base 10:

  1. Se identifica el índice posicional i de cada dígito: hacia la izquierda del punto radical se asignan i = 0, 1, 2, …, n; hacia la derecha se asignan i = -1, -2, …, -m.
  2. Se multiplica el valor equivalente en base 10 de cada dígito di por el peso posicional bi.
  3. Se efectúa la suma algebraica total. Equivalentemente, para la parte entera puede aplicarse el Esquema de Horner: ((dn · b + dn-1) · b + …) · b + d0.

Algoritmo B: De Base 10 a Base b (División Euclídea y Multiplicación)

Si el número decimal posee parte entera y fraccionaria (N(10) = E + F), el procedimiento se divide en dos partes independientes:

  1. Parte Entera (E): Se aplica reiteradamente el algoritmo de la división euclídea Ek = b · qk + rk con 0 ≤ rk < b hasta obtener un cociente q = 0. Los residuos rk leídos en orden inverso (del último al primero) forman los dígitos en base b.
  2. Parte Fraccionaria (F): Se multiplica sucesivamente la fracción por la base b: Fk+1 = frac(Fk · b). La parte entera de cada producto (int(Fk · b)) leída en orden directo (de arriba hacia abajo) constituye los dígitos fraccionarios.

Algoritmo C: De Base b1 a Base b2 (Conversión General)

Para transformar cualquier número entre dos bases arbitrarias b1 ≠ 10 y b2 ≠ 10, se emplea la composición de los dos algoritmos anteriores utilizando la base 10 como puente intermedio:

  1. Paso 1 (Descodificación): Se transforma N(b1) → N(10) mediante expansión polinómica en potencias de b1.
  2. Paso 2 (Codificación): Se transforma N(10) → N(b2) mediante divisiones sucesivas de la parte entera entre b2 y multiplicaciones sucesivas de la parte fraccionaria por b2.
  3. Caso particular de potencias (b2 = b1k): Entre binario (2), octal (23=8) y hexadecimal (24=16) también es posible agrupar paquetes de 3 o 4 bits directamente.
